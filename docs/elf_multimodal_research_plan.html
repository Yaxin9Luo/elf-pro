ELF 多模态理解研究计划

2026-05-28 · SigLIP2 vision encoder + ELF-L latent flow；仅讨论 image+text → text，不做图像生成。

核心判断： 先把 ELF 做成一个强的多模态理解 baseline，而不是一开始追求统一多模态生成。视觉侧只作为 condition prefix，ELF 仍在 T5 latent space 里生成答案文本。当前最好的初始化是 ELF-L epoch 3 / checkpoint_57051，因为它在 64-step SDE 上达到 PPL 21.27 / entropy 5.18，优于原版 ELF-L headline 的 PPL 23.3 / entropy 5.28。

一、目标与边界

目标

Image + Text → Text

给定一张图和一个文本 prompt，ELF 在 latent space 中生成 answer/caption，再通过 DLM head 解码成 token。

image + user prompt
  → visual condition tokens + prompt latents
  → ELF flow denoise answer latents
  → DLM head decode answer tokens
边界

不做统一多模态生成

第一版不生成 image/audio/video，不训练可反演的多模态 shared latent space，也不引入 Q-Former/Perceiver 或 auxiliary alignment loss。

核心问题是：一个强文本 ELF prior 加简单视觉 projector，能否形成可训练、可比较的多模态理解 baseline。

研究品味约束： baseline 必须简单、可复现、能被强对照实验验证。先证明视觉条件真的被 ELF 用上，再讨论更复杂的 alignment space 或视觉 tower。

二、文本 prior：为什么用 epoch 3 ELF-L

按同样 3 epochs 比，你们的 ELF-L 复现已经超过原版 headline。多模态 finetune 的最终输出仍然是文本，因此更强的 text prior 会直接改善 caption/VQA/instruct 的起点。

模型 / checkpointEval configPPL ↓Mean entropy ↑判断
Original ELF-L SDE 64 steps 23.3 5.28 paper headline
ours ELF-L epoch 3 / checkpoint_57051 SDE 64 / gamma 1.0 21.2668 5.1782 PPL 好 2.03；entropy 低 0.10，但未坍缩
ours ELF-L epoch 3 / checkpoint_57051 SDE 32 / gamma 1.5 27.8613 5.2650 32-step 质量不如 64-step，适合做 NFE ablation
默认初始化： 多模态实验优先使用 checkpoint_57051 的 EMA 权重，配置为 init_checkpoint_use_ema: true、init_checkpoint_strict: false。不要默认用 epoch 5 final，因为 final 的 PPL 已经回退到 23.67 左右。

三、模型方案：SigLIP2 → projector → ELF

当前实现已经落到代码里：src/modules/vision_encoder.py 加载 frozen SigLIP2，src/modules/model.py 内置 VisionProjector，src/utils/multimodal_utils.py 组装多模态 latent 序列。

SigLIP2 image encoder (frozen)
  → patch tokens [B, P, d_v]
  → adaptive pool to 8x8 = 64 tokens
  → LayerNorm → Linear → GELU → Linear
  → visual condition latents [B, 64, d_t5]

T5 encoder (frozen)
  → prompt latents + target answer latents

ELF input sequence:
  [visual_cond_latents] + [prompt_latents] + [target_answer_latents]
组件默认选择训练状态原因
Vision encoder google/siglip2-base-patch16-224 frozen 语义 alignment 干净，作为第一版比 QwenViT 更容易诊断
Text encoder t5-small frozen 保持 ELF 原始 latent space，不引入额外变量
Projector LN → Linear → GELU → Linear trainable 最小 bridge；能验证视觉条件是否能被 ELF 使用
ELF ELF-L 优先，ELF-B 作快速 smoke Stage 1 frozen；Stage 2 trainable 先学 bridge，再让 latent flow 适配视觉条件

四、训练阶段与 ablation

Phase 0 · Text ELF-L checkpoint 固化

固定使用 epoch 3 checkpoint_57051 作为多模态初始化。记录它在 OWT 上的 PPL 21.27 / entropy 5.18，后续多模态 finetune 不再混淆 text pretraining 变量。

Phase 1 · Projector warmup

数据用 LLaVA pretrain / caption 数据。冻结 SigLIP2、T5、ELF，只训练 projector；目标是 image condition → caption generation，不加 cosine/MSE/contrastive auxiliary loss。

config: train_llava_siglip2_warmup_ELF-B.yml / ELF-L variant
train_stage: vision_warmup
trainable: vision_projector only
loss: existing ELF CE/L2 target-only loss

Phase 2 · Multimodal instruction finetune

数据用 LLaVA-Instruct / LLaVA-OneVision single-image subset。冻结 SigLIP2、T5，训练 projector + ELF；projector learning rate 默认是 ELF 的 5 倍。

config: train_llava_siglip2_instruct_ELF-B.yml / ELF-L variant
train_stage: mm_instruct
trainable: vision_projector + ELF
loss: existing ELF CE/L2 target-only loss

五、评测指标与成功标准

主比较应该是同等数据、同等视觉 encoder 下，ELF 多模态 baseline 与简单 AR/VLM baseline 的生成质量和成本。不要把 ELF 的 generative PPL 与 AR validation PPL 混比。

Caption

COCO / LLaVA pretrain eval

ROUGE / BLEU 只作快速 sanity；重点看生成是否贴图、是否重复、是否短模板化。

VQA

VQAv2 / GQA / TextVQA

用 exact match / normalized accuracy。TextVQA 可以检验 SigLIP2 baseline 在 OCR 弱项上的边界。

Instruction

LLaVA-Bench / MM-Vet 子集

保存 JSONL，必要时用 LLM judge；第一版不把 judge 分数当唯一主结果。

成功标准最低要求强结果
视觉条件有效 A2 明显优于 shuffled image A4 A2 在 caption/VQA 上稳定超过 A3
ELF 可多模态适配 Stage 2 解冻 ELF 后不破坏基本文本生成 ELF-L 初始化明显优于 ELF-B 或 random projector direct tuning
生成质量 非空、非重复、能跟随 prompt caption/VQA 接近简单 LLaVA-style AR baseline

六、风险与下一步

最大风险： SigLIP2 的 patch features 虽然语义 alignment 好，但不是专门为 ELF/T5 latent space 训练的。MLP projector 可能学到可用 condition，但细粒度 OCR、定位、计数会弱。
风险症状处理
只靠语言 prior shuffled image control 仍然答得很好 提高视觉相关数据比例；加入 hard negative VQA；降低 prompt-only shortcuts
finetune 后模板化 entropy/repetition 变差，答案变短 降低 ELF lr；增加 caption/open-ended QA；保留 best checkpoint 而非 final
MLP bridge 不够 warmup loss 降不动，A2 不优于 A1 第二版再上 Perceiver/Q-Former，不在第一版引入
SigLIP2 感知不足 OCR/layout/chart 任务弱 后续引入 QwenViT / InternViT 作强感知对照
下一步执行顺序： 先用 ELF-B 配置跑 8-16 条 fake/LLaVA 样本 smoke；再用 ELF-L + checkpoint_57051 跑 projector warmup；最后做 A1/A2/A3/A4 ablation。所有结果同时记录 task metric、生成样本、entropy/repetition 和采样成本。
